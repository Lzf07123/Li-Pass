## 1. 方案定位与决策时间线

目标一句话：在「安全可信」不丢失的前提下，把 Li&Pass 从单一「安全蓝 + 石板灰」升级为
**全淡色的海玻璃系统 + 可见的科技流动光效 + 优雅的文字/计数动效**。

决策时间线（与用户逐轮收敛，全部保留在 CHANGELOG 与 spec 增补中）：

1. 「颜色太单调」→ 引入六色强调色板与基础流动光效；
2. 「主界面也要光效、有科技感」→ 设计 TechAmbience（网格 + 光束 + 光点）；
3. 「跳出设计限制做独特配色」→ 提出深空极光方向；
4. 「全部淡色、不要重色」→ 回到全淡色系；
5. 「不要粉色系」→ 移除粉/品红，第六色相改 lime；
6. 七套色卡中选定 **H · 海玻璃**；
7. 「深色页面还是太重」→ 深色改为 **D1 雾灰** 柔和中间调；
8. 「按钮颜色太重、违和」→ 按钮改**半透明单色着色**；
9. 「强化光效、后台也加上」→ 光束/光点/网格提亮，后台接入淡版；
10. 「让光效动起来」→ 修复缺失的关键帧并整体提速；
11. 「极光太快」「光束光点也等比放慢」→ 极光 18/22/28/24s，光束 10s、光点 6s；
12. 主文字改用 React Bits **BlurText**、全部计数改用 **CountUp**；
13. 按钮状态审计：pending 只出现在被点击的按钮上。

## 2. 硬约束（不可破）

- **全淡色**：所有表面与装饰为浅色/雾面；**无粉色系、无大面积重色**。
- **WCAG AA**：正文 ≥ 4.5:1、图形/UI ≥ 3:1；所有强调色 strong-on-soft 组合已核算通过。
- **动效纪律**：只动 `transform/opacity/background-position`；每个 `animation` 必须有对应
  `@keyframes`；`prefers-reduced-motion` 降为单帧；移动端减量。
- **单一事实来源**：颜色/动效令牌只在 `index.css`；品牌文案只在 `brand.ts`；组件不硬编码 hex。
- **语义不混**：强调色只做装饰；成功/警告/危险永远走语义色。

## 11. RGB 色值调校方法（可直接照做）

所有色值都改在 `frontend/src/index.css` 的 `:root`（浅色）与 `.dark`（深色）两处；
模板版对应 `reusable-tokens.template.css`。下面给出手算规则、公式与可粘贴的校验脚本。

### 11.1 RGB ↔ HSL 基础换算

记 R/G/B ∈ [0,255]，归一化 `r=R/255`，`max`/`min` 为三通道最大/最小值：

- 亮度 `L = (max + min) / 2`
- 饱和度 `S = 0`（max = min）；否则 `S = (max-min) / (1 - |2L-1|)`
- 色相 `H`：max=R 时 `60·(((G-B)/(max-min)) mod 6)`；max=G 时 `60·((B-R)/(max-min)+2)`；
  max=B 时 `60·((R-G)/(max-min)+4)`；负值 +360。

调校直觉（最重要三条）：

1. **改亮度**：三通道同加/同减（保持差值）→ 整体变亮/变暗、色相基本不变。
2. **改饱和**：三通道差距越大越艳，差距越小越灰（雾面 = 差距小）。
3. **保持色相只调亮度**：优先在 HSL 空间改 `L`（把 H/S 固定），避免手改单个通道把色相带偏。

### 11.2 各角色的目标区间（海玻璃基准）

| 角色 | 浅色目标 | 深色目标 |
| --- | --- | --- |
| 背景 bg | `L≈96–98%`（RGB≈245–252），色相 tint 只差 1–4 个值 | 雾灰 `L≈22–28%`（RGB≈56–72），**不压黑** |
| 表面 surface | 纯白或比 bg 亮 2–4 | 比 bg 亮 6–10 |
| 表面 2 | bg 与 surface 的中点 | 同左 |
| 前景 fg | `L≈18–25%`（RGB≈46–64），对 bg 对比 ≥ 4.5:1 | `L≈88–95%` |
| 弱化 muted | `L≈40–48%` | `L≈64–72%` |
| 边框 border | 与 bg 同色相、亮度再低 8–12 | 比 surface 亮 10–16 |
| 主色 primary | 该色相 600–700 档（海玻璃 `#2F7F74`，`L≈33%`） | 该色相 300 档（`#7FD4C6`，`L≈70%`） |
| 强调色 strong | 同主色：浅 600–700 档、深 300 档 | — |
| 强调色 soft | `rgba(strong, 0.14–0.18)` 叠 surface | 同左 |
| 按钮 | bg `rgba(主色, 0.10)`（深 0.13）、hover ×1.6–1.7、描边 ×2.5–3 | 同左 |

**雾面感的定量含义**：`S ≤ 25%`；把 S 调到 35% 以上就开始「艳」、与全淡色口径冲突。

### 11.3 WCAG 对比度核算（正文 ≥ 4.5:1）

相对亮度（sRGB）：`lin(c) = c/255 ≤ 0.03928 ? c/255/12.92 : ((c/255+0.055)/1.055)^2.4`；
`L = 0.2126·lin(R) + 0.7152·lin(G) + 0.0722·lin(B)`；
对比度 `CR = (L_light + 0.05) / (L_dark + 0.05)`。正文 ≥ 4.5，大字号/图形 ≥ 3。

可粘贴的校验脚本：

```python
def lum(hex_color):
    h = hex_color.lstrip("#")
    rgb = [int(h[i:i+2], 16) / 255 for i in (0, 2, 4)]
    lin = [c / 12.92 if c <= 0.03928 else ((c + 0.055) / 1.055) ** 2.4 for c in rgb]
    return 0.2126*lin[0] + 0.7152*lin[1] + 0.0722*lin[2]

def contrast(a, b):
    la, lb = lum(a), lum(b)
    return (max(la, lb) + 0.05) / (min(la, lb) + 0.05)

print(contrast("#35423F", "#F6FBF9"))   # 前景/背景，应 ≥ 4.5
print(contrast("#25786D", "#D9F4EE"))   # strong/soft，应 ≥ 4.5
```

### 11.4 「无粉色」与「无重色」判定

- **粉色/玫瑰系判据**：`R > G + 30` 且 `B ≥ G - 20`（红高、绿低、蓝不低）。珊瑚橙例外是
  `B` 明显更低；玫红/品红是 `B` 与 `R` 都高。选色后用判据扫一遍强调色与渐变停靠点。
- **重色判据**：大面积用色 `L < 10%`（RGB 均值 < 26）即属重色；Bento 小卡这类小面积深底除外。
- **深色软底上限**：`rgba(浅色, 0.14–0.18)` 软底 + 同色浅字的对比上限 ≈ 3.9，**不可能**达到
  4.5。需要文字时二选一：① 实色粉彩底 + 深色文字（`#17332E`，对比 7+）；② 文字改高亮近白浅色
  （如 `#CFF0DE`）。只有图标/图形可以留在 3:1 档。

### 11.5 浅色 ↔ 深色映射法

保持 H、S 不变，只把 L 换到「互补档」：

| 浅色角色 | 深色对应档 |
| --- | --- |
| bg 96–98% | 22–28% |
| fg 18–25% | 88–95% |
| muted 40–48% | 64–72% |
| primary/strong 33% 档 | 70%+ 档 |

例：浅主色 `#2F7F74`（HSL ≈ 173°/46%/33%）→ 深主色 `#7FD4C6`（173°/46%/66%）。

### 11.6 六步调校工作流

1. **定 H**：保持色相不动（改色相是换方案，不是调校）。
2. **定 L**：按 §11.2 角色表先落到目标亮度档。
3. **定 S**：雾面 10–25%，需要更醒目再往 30% 靠，不超过 35%。
4. **验对比**：跑 §11.3 脚本，fg/bg、strong/soft 全部 ≥ 4.5。
5. **查禁忌**：§11.4 判据扫粉色与重色；语义色不挪作装饰。
6. **双主题同步 + 落地**：`:root` 与 `.dark` 成对改；回写本文件与模板附录；截图/像素采样复核。
